# 競馬予想の相棒メモ（keiba-notes ブランチ）

ゲーム本体（main）とは別の、競馬予想の記録用ブランチ。main にはマージしない。

- `lessons.md` — 振り返りから得た教訓・予想ルールの調整（毎回の予想の前に必ず読む）
- `watchlist.md` — 次走注目馬（人気薄で激走・出遅れ/不利から上位など）
- `predictions/YYYY-MM-DD.md` — その日の予想（印・紐・理由）
- `reviews/YYYY-MM-DD.md` — その日の結果と振り返り
